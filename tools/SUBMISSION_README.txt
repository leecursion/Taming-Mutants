================================================================
  돌연변이 길들이기 (Taming Mutants)
  단백질 구조를 직접 만지며 배우는 과학 교육 게임
================================================================

[ 실행 방법 ]

  1. 압축을 푼 폴더에서 TamingMutants.exe 를 실행합니다.
  2. 폴더 구조를 유지해 주세요. exe만 따로 옮기면 실행되지 않습니다.
  3. Windows SmartScreen 경고가 뜨면
     [추가 정보] > [실행]을 눌러 주세요.
     (코드 서명 인증서가 없는 개인 개발 빌드라 표시되는 안내입니다.)


[ 조작법 ]

  마우스 좌클릭        오브젝트 / 원자 선택
  마우스 우클릭 드래그  단백질 구조 회전
  마우스 휠            확대 / 축소
  ESC                  이전 화면으로

  화면의 마이크 버튼   AI 조수에게 음성으로 질문
                       (버튼을 누르고 말한 뒤 다시 눌러 전송)


[ AI 기능 ]

  게임 안의 AI 조수에게 자유롭게 질문할 수 있습니다.
  글로 입력하거나, 마이크 버튼을 눌러 말로 물어봐도 됩니다.
  조수는 중학생 눈높이에 맞춰 답하고, 답을 소리 내어 읽어 줍니다.

  - 대화        Upstage Solar
  - 음성 인식   OpenAI Whisper
  - 음성 합성   OpenAI TTS

  API 키는 게임에 포함되어 있지 않습니다.
  모든 AI 요청은 자체 백엔드 서버(Cloudflare Workers)를 거쳐 처리되며,
  키는 서버에만 보관됩니다.

      게임  ->  자체 백엔드 서버  ->  LLM 제공자
                (키 보관 / 프롬프트 주입)


[ 실행 환경 ]

  운영체제   Windows 10 / 11 (64비트)
  인터넷     AI 기능 사용에 필요합니다.
             연결이 없어도 게임 진행 자체는 가능하며,
             이때 조수는 미리 준비된 대사로 안내합니다.
  마이크     음성 질문에만 필요합니다. 없으면 마이크 버튼이
             표시되지 않고, 글로 질문하는 방식은 그대로 동작합니다.

  방화벽이 외부 HTTPS 요청을 차단하는 환경에서는 AI 응답이
  오지 않을 수 있습니다. 그 경우 함께 제출한 시연 영상을
  참고해 주시면 감사하겠습니다.


[ 사용한 데이터 ]

  단백질 구조 데이터는 AlphaFold DB / RCSB PDB의 공개 데이터를
  사용했습니다. 구조 색상은 예측 신뢰도(pLDDT)를 나타냅니다.
