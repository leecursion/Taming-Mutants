# 돌연변이 길들이기 · Taming Mutants

> 단백질 구조를 직접 관찰하고, AI 조수와 함께 돌연변이의 비밀을 풀어가는 과학 교육 게임

## 프로젝트 소개

**돌연변이 길들이기**는 Unity로 제작한 Windows PC용 3D 과학 교육 게임입니다. 가상 연구실에서 단백질을 회전하고 확대하며, 작은 구조 변화가 단백질의 역할에 어떤 영향을 주는지 탐구합니다.

플레이어는 연구자가 되어 변이 부위를 찾고, 후보 물질을 비교하고, 실험 결과를 바탕으로 선택의 근거를 설명합니다. AI 조수 **Co-Scientist**가 대화와 음성으로 탐구를 돕습니다. 생명과학에 관심 있는 학생이 구조 관찰부터 문제 해결까지 직접 경험할 수 있도록 구성했습니다.

## 주요 기능

- **3D 구조 관찰**: 단백질과 분자를 회전·확대하고, 원자와 변이 부위를 살펴봅니다.
- **사례 탐색**: 다섯 가지 돌연변이 사례를 따라 구조와 기능의 관계를 배웁니다.
- **AI 분자 탐색**: 보고 싶은 분자를 말하거나 입력해 검색하고, 3D 구조를 관찰합니다.
- **후보 물질 실험**: 후보 물질을 비교하고, 분자가 단백질에 결합하는 위치와 자세를 살펴보는 도킹 실험을 진행합니다.
- **AI 조수와 대화**: 글이나 음성으로 질문하고, 현재 탐구 상황에 맞는 설명을 듣습니다.
- **학습 확인과 복습**: 후보 물질을 선택한 근거를 설명하고, 피드백을 통해 놓친 개념을 돌아봅니다.

## 탐색 모드

### 사례 탐색

준비된 사건을 선택해 **상황 파악 → 구조 관찰 → 실험과 후보 선택 → 결과 확인과 설명** 순서로 탐구합니다. 사례마다 실험 방식과 해결 과정이 달라집니다.

| 사례 | 탐구 주제 |
| --- | --- |
| KRAS G12C | 멈추지 않는 세포 성장 신호와 변이 부위를 겨냥한 후보 물질 |
| EGFR L858R | 신호 전달 단백질의 변화와 결합 부위 탐색 |
| ABL1 T315I | 변이로 달라진 결합 부위와 약물 내성 |
| CFTR F508del | 단백질의 접힘과 이동, 채널 기능 회복 |
| p53 Y220C | 온도에 따른 구조 안정성과 변이로 생긴 틈 |

### AI 분자 탐색

궁금한 분자를 채팅이나 음성으로 요청하고, 검색된 구조를 3D로 살펴보는 모드입니다. 리본과 원자 상세 보기로 구조를 관찰하며 AI 조수에게 질문할 수 있습니다. 단백질과 후보 물질을 선택해 도킹 실험으로 탐구를 이어갈 수도 있습니다.

## 시작하기

### Windows 실행 파일로 체험하기

1. 배포용 빌드의 압축을 풉니다.
2. 폴더 안의 `TamingMutants.exe`를 실행합니다. 실행 파일과 함께 제공되는 데이터 폴더는 같은 위치에 유지해 주세요.
3. 화면에서 **사례 탐색** 또는 **AI 분자 탐색**을 선택합니다.
4. AI 조수와 화면의 안내에 따라 탐구를 시작합니다.

### 실행 환경

| 항목 | 안내 |
| --- | --- |
| 운영체제 | Windows 10 / 11, 64비트 |
| 입력 장치 | 마우스와 키보드 |
| 인터넷 | AI 대화·음성 처리, 온라인 분자 검색 및 도킹 계산에 필요 |
| 마이크 | 음성 질문을 사용할 때 필요 |

온라인 기능을 사용하려면 연결된 백엔드 서비스가 운영 중이어야 합니다.

### 기본 조작

| 입력 | 동작 |
| --- | --- |
| 마우스 좌클릭 | 버튼, 오브젝트 또는 원자 선택 |
| 마우스 우클릭 드래그 | 구조 회전 |
| 마우스 휠 | 확대·축소 |
| 채팅 입력창 | AI 조수에게 글로 질문 |
| 마이크 버튼 | 음성 질문 시작, 다시 눌러 전송 |
| 화면의 뒤로 가기·나가기 버튼 | 이전 단계 또는 모드 선택 화면으로 이동 |

### Unity에서 실행하기

1. Unity Hub에서 이 저장소 폴더를 프로젝트로 추가합니다.
2. **Unity 6000.5.3f1**로 열고 패키지와 에셋 로딩이 끝날 때까지 기다립니다.
3. `Assets/Scenes/Lab_Desktop.unity` 씬을 열고 Play 버튼을 누릅니다.

AI 및 온라인 기능의 서버 설정은 [백엔드 안내](server/README.md)를 참고하세요.

## 기술과 데이터

- **게임 엔진**: Unity 6, Universal Render Pipeline(URP), C#
- **AI 대화**: Upstage Solar
- **음성 인식·합성**: OpenAI Whisper / TTS
- **백엔드**: Cloudflare Workers 및 도킹 계산 서비스
- **구조 데이터**: AlphaFold DB / RCSB PDB의 공개 단백질 구조 데이터
