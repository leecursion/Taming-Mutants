# 사건 1–5 상호작용 변경

후보 클릭 → 분자 관찰/좌우 회전 → 예상 효과 선택 → 실험 시작 → 결과 기록 → 기능 검증 순서로 진행한다.
후보 이름과 부제는 관찰 가능한 특징을 보여 주며 정답 판정은 실험 후 공개한다.

- 사건 1: 포켓 진입, 고정, 충돌, 결합 불일치를 구별하고 성장 신호 감소를 확인한다.
- 사건 2: 전용 후보 JSON을 사용하며 Cys797 결합과 EGFR 하위 신호 변화를 연결한다. 분자 골격은 기존 교육용 후보를 재사용한다.
- 사건 3: 후보별 진입 깊이(clash_depth)가 달라진다. 불안정한 결합은 반응기 부재와 별도 판정이다.
- 사건 4: 부분 회복/분해 경로 차단을 충돌·이탈과 분리한다. corrector 성공 후 구조 교체가 끝나야 다음 후보를 실험한다. potentiator를 먼저 선택하면 선행 작업 안내를 기록한다.
- 사건 5: 도킹 후 37°C 검증 버튼을 눌러 기존 처리 전후 및 DNA 결합 연출을 진행한다. 완료는 기능 검증 뒤에 처리한다.

## 화면 배치

ThermalStabilityController는 현재 보이는 원자 렌더러의 경계를 기준으로 카메라 거리를 계산한다. 원자 반지름, 깊이, 열 흔들림 여유를 포함하고 후보/비서/온도/실험 패널 공간을 남긴다. 기존 카메라 복귀 처리는 유지한다.
AIAssistantFollower는 데스크톱에서 본체와 말풍선 전체의 화면 점유율을 폭 25%, 높이 34% 이하로 제한한다. 원래 크기를 기준으로 매번 계산하므로 프레임마다 축소가 누적되지 않는다. XR 카메라에는 이 크기 제한을 적용하지 않는다.

## 데이터와 동작

- CompoundData: observation, clash_depth, forms_covalent_bond 추가.
- 새 판정: PartialRecovery, DegradationBlocked, UnstableBinding.
- 기록은 현재 사건 안에서 유지한다. 실험 기록 버튼과 좌우 버튼으로 이전 기록을 비교한다. 다른 사건을 시작하면 초기화한다.
- 새 UI는 CompoundSelectionPanel에서 자동 생성한다. 씬에 수동으로 추가할 필요가 없다.
- 표기되는 신호 변화는 교육용 연출이며 실시간 도킹 계산이나 실측 효능 수치가 아니다.

## 확인 항목

- 데이터 검증: 사건 5개 / 후보 23개, 파일 참조, 선행 성공 조건, 판정 enum, 한글, 결합 인덱스, 기존 원자/결합/친화도 데이터 보존.
- C# 빌드: Assembly-CSharp.csproj 및 에디터 프로젝트.
- Unity 플레이에서 추가 확인: 사건 5의 서로 다른 나선 구간과 20–60°C, 이전/재진입, 16:9 및 좁은 창에서 원자·비서 크기, 후보 변경과 기록 비교, CFTR 순서 오류/부분 회복/두 단계 성공, 37°C 검증 후 사건 선택 화면 복귀.
- 실제 게임 화면의 배치와 조작은 이번 코드 검증만으로 확인된 사항이 아니다.

## 모든 사건의 공통 화면 배치

- 관찰·예상·실험 시작·기록 패널을 왼쪽 아래에 배치한다. 왼쪽·아래 가장자리에서 각각 16px(1600×900 기준)만 띄운다.
- 데스크톱의 모든 사건에서 비서는 분자 경계 대신 본체와 말풍선의 바깥 경계를 기준으로 화면 오른쪽 위 모서리에 배치한다. 상단 82% 높이 제한은 이 모드에서 해제하고 상하 부유 여유를 둔다. 좌우 부유를 없애고 진폭 0.015m, 주기 8초의 상하 부유를 적용한다. 위치 전환은 1.5초 SmoothDamp와 최대 0.5m/s로 완화한다.
- 사건이 바뀌어도 동일한 배치와 느린 상하 부유를 유지한다. 사건 선택 전 인트로는 기존 인사 배치를 사용한다. XR은 기존 공간 배치를 유지한다.

- 모든 사건의 후보 가림 보정: 분자 표시 영역과 이름표의 화면 경계를 계산해 실험 패널 위에서 상단 정렬한다. 후보는 카메라 기준으로 diagonalYaw(기본 25°)만큼 약하게 사선 배치한다. 화면 왼쪽 위치에 따른 추가 회전은 더하지 않으며, 회전 후 분자와 이름표의 화면 경계로 겹침·잘림을 보정한다. 가로로는 표시 중인 온도·CFTR HUD의 실제 오른쪽 경계와 단백질의 왼쪽 경계 사이 공간을 사용한다. HUD 옆 20 화면 픽셀과 단백질 옆 2.5% 여백만 남기며, 기존 36% 폭 제한은 제거했다. 회전된 분자·이름표를 실측해 빈 공간이 있으면 확대하고 넘치면 축소한다. CanvasScaler와 같은 화면 배율로 하단 공간을 예약하며, 가로·세로 공간이 부족하면 전체 후보 목록을 축소한다. 후보 4개·5개와 화면비 변경에 동일한 규칙을 적용한다. 관찰창을 열기 전부터 적용해 선택 시 위치가 바뀌지 않게 한다.

## 돌연변이 실험 효과 (구현)

- 후보를 0.6초 누르면 청록·보라색 DNA 두 가닥과 염기쌍 표시가 차오르고, 관찰창이 열리며 스캔 선이 분자를 통과한다. 0.2초 미만의 짧은 클릭도 관찰을 연다. 중간 길이의 누르기, 후보 이탈, UI 진입, 창 포커스 상실, 입력 잠금, 사건 전환은 진행을 취소한다. 홀드 완료 후 버튼을 놓아도 관찰이 중복 실행되지 않는다. XR의 기존 SelectSlot 호출은 즉시 관찰과 스캔을 실행한다.
- 사건 5 변이 부위에는 보라색 맥동 윤곽을 유지한다. 주변 CA 원자의 가열 전 위치를 옅은 청록 잔상으로 표시한다. 정상형 구조를 새로 합성한 것이 아니며, 관찰 패널에도 ‘가열 전 위치’라고 표시한다.
- 온도가 높아지면 변이 주변 파동이 강해지고 불규칙해진다. 안정화 후에는 파동과 기존 원자 흔들림이 1.5초 동안 서서히 잦아든다. 보라색 변이 표시는 남는다. 온도를 최저값으로 내리면 원자도 가열 전 위치로 돌아간다.
- 사건 5 충돌·결합 불일치는 반발 파동을, 불안정한 결합·반응기 부재·일시적 결합은 흔들리며 끊어지는 접촉선을 보여 준다. 안정화 성공은 포켓 주변의 닫히는 청록 윤곽으로 표현한다. 결합선과 윤곽은 설명용 연출이며 실제 새 화학 결합 판정을 추가하지 않는다.
- DNA 결합 검증이 끝나면 방패 윤곽을 그리며, 실험 기록에 검증 완료 도장을 표시한다. 완료 화면으로 넘어가기 전 3초간 연출을 보여 준다. 기록을 추가할 때마다 ‘기록 +1’과 작은 버튼 맥동을 표시한다.
- LineRenderer 기반으로 런타임 생성되며 새 씬 설정이나 외부 이미지가 필요 없다. 임시 효과는 재생 후 삭제되고, 사건·레벨 전환 시 정리한다.

### 추가 플레이 확인

짧은 클릭 / 0.3초 취소 / 0.6초 홀드 / 홀드 중 포인터 이탈·UI 진입·포커스 상실 / 해설 잠금 / 사건 재선택을 확인한다. 사건 5에서 20→60→20°C, 안정화 성공, FragmentHit 이탈, 충돌, 37°C 검증 후 방패·도장 표시와 사건 선택 복귀를 확인한다. 실제 플레이 화면 검증은 C# 빌드만으로 대체되지 않는다.

## 화면 가장자리와 에디터 미리보기

- 실험 패널, 이전 버튼(단계 라벨 포함), 온도 조절기는 ScreenSafePanel로 Screen.safeArea 안에 들어오도록 위치와 크기를 보정한다. 안전 영역 안쪽으로 최소 20 화면 픽셀 여백을 유지한다.
- 에디터 Game 뷰를 확대하면 게임 내부 배치와 무관하게 가장자리가 잘린다. GameViewFitMenu는 플레이 시작 시 미리보기 전체가 들어오는 배율과 중앙 위치로 맞춘다. 플레이 도중 직접 확대했다면 Tools > Layout > Fit Game View를 실행한다. 이 처리는 Unity 에디터 전용이며 빌드된 게임에는 포함되지 않는다.
- 런타임·에디터 C# 빌드 확인. 실제 화면에서 사건 1~5, 후보 두 열 크기, 긴 이름표, 하단 버튼, Game 뷰 최대화/크기 변경은 플레이 확인이 필요하다.

- 상단 상태창 배경·발광·외곽선에 LayoutElement.ignoreLayout을 적용했다. 장식이 VerticalLayoutGroup의 별도 행으로 배치되던 문제를 수정해 배경은 내용 뒤에, 발광은 창 테두리에 유지된다.
- 상단 창의 부드러운 외곽선은 HoloSpriteFactory.Glow의 발광 텍스처와 bilinear 필터 설정이다. p53 HUD는 uiScale=0.72로 축소되며, Game 뷰를 2.1배 확대하면 작은 글자의 가장자리가 더 흐릿하게 보일 수 있다. 이 두 배율의 영향과 장식 레이아웃 문제는 서로 구분한다.
