# 사건 1–5 상호작용 변경

후보 클릭 → 분자 관찰/좌우 회전 → 예상 효과 선택 → 실험 시작 → 결과 기록 → 기능 검증 순서로 진행한다.
후보 이름과 부제는 관찰 가능한 특징을 보여 주며 정답 판정은 실험 후 공개한다.

- 사건 1: 포켓 진입, 고정, 충돌, 결합 불일치를 구별하고 성장 신호 감소를 확인한다.
- 사건 2: 전용 후보 JSON을 사용하며 Cys797 결합과 EGFR 하위 신호 변화를 연결한다. 분자 골격은 기존 교육용 후보를 재사용한다.
- 사건 3: 후보별 진입 깊이(clash_depth)가 달라진다. 불안정한 결합은 반응기 부재와 별도 판정이다.
- 사건 4: 부분 회복/분해 경로 차단을 충돌·이탈과 분리한다. corrector 성공 후 구조 교체가 끝나야 다음 후보를 실험한다. potentiator를 먼저 선택하면 선행 작업 안내를 기록한다.
- 사건 5: 도킹 후 37°C 검증 버튼을 눌러 기존 처리 전후 및 DNA 결합 연출을 진행한다. 완료는 기능 검증 뒤에 처리한다.

## 화면 배치

ThermalStabilityController는 현재 보이는 원자 렌더러의 경계를 기준으로 카메라 거리를 계산한다. 원자 반지름, 깊이, 열 흔들림 여유를 포함하고 후보/비서/온도/실험 패널 공간을 남긴다. 기존 카메라 복귀 처리는 유지한다.
AIAssistantFollower는 데스크톱에서 본체와 말풍선 전체의 화면 점유율을 폭 25%, 높이 34% 이하로 제한한다. 원래 크기를 기준으로 매번 계산하므로 프레임마다 축소가 누적되지 않는다. XR 카메라에는 이 크기 제한을 적용하지 않는다.

## 데이터와 동작

- CompoundData: observation, clash_depth, forms_covalent_bond 추가.
- 새 판정: PartialRecovery, DegradationBlocked, UnstableBinding.
- 기록은 현재 사건 안에서 유지한다. 실험 기록 버튼과 좌우 버튼으로 이전 기록을 비교한다. 다른 사건을 시작하면 초기화한다.
- 새 UI는 CompoundSelectionPanel에서 자동 생성한다. 씬에 수동으로 추가할 필요가 없다.
- 표기되는 신호 변화는 교육용 연출이며 실시간 도킹 계산이나 실측 효능 수치가 아니다.

## 확인 항목

- 데이터 검증: 사건 5개 / 후보 23개, 파일 참조, 선행 성공 조건, 판정 enum, 한글, 결합 인덱스, 기존 원자/결합/친화도 데이터 보존.
- C# 빌드: Assembly-CSharp.csproj 및 에디터 프로젝트.
- Unity 플레이에서 추가 확인: 사건 5의 서로 다른 나선 구간과 20–60°C, 이전/재진입, 16:9 및 좁은 창에서 원자·비서 크기, 후보 변경과 기록 비교, CFTR 순서 오류/부분 회복/두 단계 성공, 37°C 검증 후 사건 선택 화면 복귀.
- 실제 게임 화면의 배치와 조작은 이번 코드 검증만으로 확인된 사항이 아니다.
